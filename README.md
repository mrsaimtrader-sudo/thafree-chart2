# The Free Chart - Android WebView app

## Option A: Android Studio
1. Android Studio > File > Open > ye folder choose karo
2. Gradle sync hone do
3. Build > Build APK(s)  ->  app/build/outputs/apk/debug/app-debug.apk

## Option B: Bina Android Studio (GitHub Actions)
1. github.com pe naya repo banao, is folder ki saari files upload/push karo
2. Repo > Actions > "Build APK" > Run workflow
3. Run complete hone par "TheFreeChart-APK" artifact download karo, zip ke andar app-debug.apk hai
4. Phone me install karo (Unknown sources allow karna padega)
